# Modernization Checklist

- [ ] Reproducible project tooling and dependency lock
- [ ] Offline characterization tests
- [ ] Validated configuration
- [ ] Provider timeout/retry/error policy
- [ ] Correlation IDs and structured failure records
- [ ] Versioned schema migrations
- [ ] UTC timestamps and SQLite concurrency policy
- [ ] Versioned model pricing
- [ ] Pluggable, validated evaluation records
- [ ] Safe bounded LLM-as-judge execution
- [ ] Tested API contracts, pagination, and filters
- [ ] Dashboard authentication and production hardening
- [ ] Redaction, retention, and deletion controls
- [ ] Health/readiness and structured service logs
- [ ] Production packaging, backup, migration, and rollback docs
- [ ] Final end-to-end verification
